Research-integrity prototype

Every paper stands on its citations. Some of them have already fallen.

CIC reads a paper's reference list, checks each source against the retraction record, and scores how heavily the paper's evidence rests on withdrawn work — weighting fabrication far above honest error, and following the chain one hop deeper. It produces an attention flag with an itemized ledger, not a verdict.

minor
Tiers 3–2 = misconduct — summed undiluted, so one load-bearing fabrication moves the score regardless of bibliography length. Tiers 1–0 = minor — density-normalized, so a long list of harmless retractions can't manufacture a false alarm.
02

How the score is built

Three factors multiply — the score only spikes when a serious retraction is relied upon.
riski  =  severity × reliance × staleness
FinalRisk  =  Σ riski over misconduct refs  +  ( Σ riski over minor refs ) / √(#refs)
severity × reliance × staleness

Severity from the tier ladder. Reliance is a conservative v1 default of 1.0 (OpenAlex gives no in-text context) — it can only over-flag, never hide. Staleness amplifies from 1.0 to 1.5 the longer a retraction sits cited-and-unaddressed.

why the split

Misconduct-tier hits are summed at full weight; minor hits are divided by √(#refs). Every coefficient here is a labeled default to be tuned against the validation set — validate.py reports ROC-AUC on matched case/control papers — not defended as correct.

One hop deeper (--depth 2)

Retractions reached through your references — with the entry point named.

CIC can walk one hop out to find retractions a paper reaches indirectly, attribute which reference each one enters through, and decay its risk. Anything already counted at depth 0–1 is excluded, so nothing is double-charged.

HOP 0 the audited paper reference list read
HOP 1 direct citations full weight
HOP 2 citations-of-citations decayed · entry point attributed

CIC · Citation Integrity Checker — Python CLI · MIT source on github ↗

Built on open data from OpenAlex and Retraction Watch / Crossref. Retraction ≠ wrong: retractions span honest error to fabrication, the severity tiers exist so harmless ones don't trigger alarm, and the reason string is surfaced verbatim so a human can overrule the tier. A flag means a cited work was later withdrawn — information a reader deserves, not an accusation against the citing paper.
